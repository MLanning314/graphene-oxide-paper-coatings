# graphene-oxide-paper-coatings
Analysis for data collected on the project "Ultrathin Graphene Oxide Coatings as Surface Modifiers of Cellulosic Paper: Decoupling Performance Improvement from Mass Addition in Porous Fiber Networks"

The main repository houses all of the subdirectories and r-scripts that were used in the analysis/preparation of the manuscript submitted to ACS **need to add here**, as well as the completion of an Honors Thesis for the Department of Earth, Environmental, and Planetary Sciences at Northwestern University.

## Directory
### Folders
- `data`: contains the Excel file with all the data collected on this project from 2023 to 2026.
- `honors_thesis`: contains the analysis and figures used in the Honors Thesis "Graphene Oxide as an Environmentally Friendly Alternative to PFAS and Plastic Modifiers in Paper Packaging" 
- `manuscript`: contains the analysis and figures used in the ACS manuscript "Ultrathin Graphene Oxide Coatings as Surface Modifiers of Cellulosic Paper: Decoupling Performance Improvement from Mass Addition in Porous Fiber Networks"
